## 1. NexusMarket (`/digital-marketplace`)
- **Category:** E-Commerce & Digital Asset Marketplace
- **Description:** A worldwide digital asset marketplace built for AI builders and software engineers — featuring AI models, M-Pesa SDKs, Python automation tools, and UI kits with multi-currency checkout (USD/KES) and instant delivery.
- **Repository:** [Coder-Kim-bit/digital-marketplace](https://github.com/Coder-Kim-bit/digital-marketplace)
- **Live Entry Point:** [`./digital-marketplace/index.html`](./digital-marketplace/index.html)
- **Tech Stack:** HTML5, CSS3, Vanilla JavaScript, Multi-threaded Python server, LocalStorage

## 2. FreelancerHub (`/freelancerhub`)
- **Category:** Fintech & Kenyan Tax Compliance
- **Description:** A privacy-first browser dashboard for freelancers in Kenya. Keeps all data in local storage, automates Kenyan tax compliance (3% Turnover Tax, 16% VAT), generates professional invoices, and tracks cash flow against KRA eTIMS requirements.
- **Live Entry Point:** [`./freelancerhub/index.html`](./freelancerhub/index.html)
- **Tech Stack:** HTML5, CSS3, JavaScript, LocalStorage, Print-ready CSS
